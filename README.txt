QUICK START
1. Unzip the folder.
2. Upload ALL SIX website files (index.html, guide.html, districts.html, style.css, data.js, app.js) to the ROOT of your existing GitHub repository voter-guide-2026. Do not upload the enclosing folder.
3. Commit changes. GitHub Pages will update shortly.
4. Edit data.js to replace example placeholder entries with verified contests and your recommendations.

DATA FORMAT
scope: statewide / regional / berkeley / oakland / district
For district entries also set city, districtType and district.
recommendation: short label, e.g. YES, NO, or a candidate name
summary: 1–2 sentences, shown in Explained and Detailed
 details: full analysis, shown only in Detailed
sources: [{label:'Official analysis',url:'https://...'}]

IMPORTANT
The supplied data is PLACEHOLDER content, not a complete or verified ballot. Add all contests after checking official materials. The district selector only displays districts for which you add entries.
